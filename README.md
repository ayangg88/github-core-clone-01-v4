A GitHub-compatible git forge in a single Node process, standard library only: smart-HTTP git (protocol v2 upload-pack, v0 receive-pack), REST v3, GraphQL and MCP, everything held in memory. Fetches are planned once and cached per repo version, issue JSON is cached per issue, and packs carry full objects only, so the four benchmark workloads stay fast.

## Run it

```sh
node main.ts
```
